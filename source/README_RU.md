**StrangeVisuals** — клиентский мод нового поколения для Minecraft Fabric 1.21.11, ориентированный на визуальное улучшение игры, кастомизацию и производительность. Мод построен на базе современного графического пайплайна Blaze3D от Mojang и специализированных GLSL шейдеров, предлагая пост-обработку картинки, эффекты рук от первого лица, интерактивный HUD и полноценный медиаплеер с синхронизированным отображением текста песен (LRC).

## ✨ Основные возможности

### 🎨 Продвинутые пайплайны пост-обработки
- **Ambience & Bloom**: многоуровневая пирамида блума (даунсемплинг в 1/2, 1/4 и 1/8 разрешения), тонкая настройка экспозиции, контраста, насыщенности и кинематографичной виньетки.
- **Процедурное небо (Shader Sky)**: собственный рендерер инвертированного куба неба из 36 вершин с расчетом астрономического времени, плотности звезд и градиентных акцентов.
- **Экранный дождь (Rain)**: физически корректное преломление капель и искажение картинки в зависимости от силы осадков.
- **Эффекты ударов и убийств**: волновые пузыри искажения в экранном пространстве (Hit Bubbles) и вспышки при уничтожении противников (Kill Effects).

### ✋ Кастомизация рук от первого лица и визуальные эффекты
- **Обводка рук (Hand Outline)**: извлечение геометрии рук через дельту буфера глубины (`Line`, `Glow`, `Aura`, `Energy`).
- **Следы движения и дым (Hand Trails)**: темпоральный эффект шлейфа и дыма за оружием и руками в движении.
- **Редактор положения рук (Hand Editor)**: детальная настройка смещения, вращения и масштаба предметов в основной и второй руке.

### 🎵 Встроенный медиаплеер и текст песен в реальном времени
- **Интеграция с Windows Media**: прямое взаимодействие с WinRT (System Media Transport Controls) — автоматическое определение трека из Spotify, Apple Music, YouTube Music, Deezer, Яндекс Музыки, Foobar2000 и браузеров.
- **Синхронизированные слова (LRC)**: моментальная подгрузка таймингов текста песен через API lrclib с отображением текущей и следующей строк в HUD.
- **Обложки альбомов**: асинхронное получение оригинальной обложки из iTunes API с процедурной градиентной генерацией при отсутствии сети.

#### 🖥️ 100% Кастомный интерфейс, Редактор меню и пресеты
- **Интерактивный редактор главного меню**: Полноценный визуальный редактор прямо в игре (кнопка в Настройки -> вкладка Стиль). Перетаскивание кнопок мышью, изменение масштаба колесиком или за угол, установка своих фотографий на фон и наложение шейдеров.
- **3 стиля-пресета**: Мгновенный сброс раскладки к пресетам **`Beta`** (фирменный скошенный стиль со стеклом), **`Modern`** (центрированная футуристичная панель) или **`Classic`** (верхняя строка навигации и компактные кнопки).
- **Свои фото и шейдерные эффекты на фоне**: Положите любое фото в `.minecraft/strangevisuals/background.png` или выберите путь, настройте затемнение и шейдерный оверлей (Bloom Pulse, Starfield, волны или зернистость).
- **Кастомное главное меню**: Полностью переработанное меню со скином игрока, физикой сглаживания (spring ease), часами и кнопкой Mod Menu.
- **Кастомный браузер серверов**: Асинхронный список с живым пингом, индикаторами задержки, поддержкой форматирования MOTD, плавным скроллом и встроенными диалогами добавления, редактирования и прямого подключения.
- **Единый центр настроек**: Вкладки **Стиль** (пресеты и запуск редактора), **Графика** (дистанция прорисовки, FPS, FOV, VSync), **Звук** (общая громкость и каналы), **Модули** (быстрые тумблеры и вызов ClickGUI) и **Система** (ресурс-паки, бинды, доступ к ванильным настройкам, переключатель языка).
- **Кастомные экраны загрузки**: Замена ванильного фона на динамический GLSL `BackgroundPipeline`, пульсирующий логотип и адаптированные под текущий стиль индикаторы подключения к серверу и загрузки мира.

### 🌐 100% Локализация (Мультиязычность)
- **Автоопределение языка игры**: Мод на лету определяет язык Minecraft и активирует соответствующий перевод.
- **Поддерживаемые языки**: Полный перевод интерфейса и настроек на **Русский** (`ru_ru`), **Украинский** (`uk_ua`) и **Английский** (`en_us`).
- **Поддержка шрифта MSDF**: Векторный рендерер шрифта с поддержкой всех букв кириллицы и украинского алфавита.

### 🎛️ Современный Fluent ClickGUI и система настроек
- **Удобные категории**: `Render`, `Visuals`, `HUD`, `Player`, `Config`.
- **Spring-анимации**: плавные физические переходы и анимации интерфейсов и контейнеров.
- **Палитра цветов и слайдеры**: точная настройка цветов (RGB / HSV) и числовых значений.
- **Сохранение конфигурации в JSON**: все переключатели, бинды, слайдеры, язык, стиль и раскладка меню автоматически сохраняются в файл `.minecraft/config/`.
- **Интеграция с Mod Menu**: отдельная кнопка перехода в список модов добавлена прямо в главное меню и настройки.

## 🛠️ Сборка из исходного кода

### Требования
- [Java Development Kit (JDK) 21](https://adoptium.net/) или новее.
- Установленный Git.

### Инструкция по сборке

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/your-username/StrangeVisuals.git
   cd StrangeVisuals/source
   ```

2. **Соберите JAR-файл мода:**
   ```bash
   # В Windows (PowerShell):
   .\gradlew build

   # В Linux / macOS:
   ./gradlew build
   ```

3. **Готовый файл:**
   Скомпилированный файл мода будет находиться по пути:
   ```text
   source/build/libs/StrangeVisuals-1.0.0.jar
   ```

4. **Запуск тестового клиента:**
   ```bash
   .\gradlew runClient
   ```

## ⚙️ Файл конфигурации

Конфигурация хранится в стандартном формате JSON в папке игры:
`.minecraft/config/strangevisuals_config.json`

Пример содержимого:
```json
{
  "modules": {
    "Ambience": {
      "enabled": true,
      "keyCode": -1,
      "settings": {
        "Exposure": 1.15,
        "Contrast": 1.05,
        "Saturation": 1.20,
        "Vignette": 0.35,
        "Fog": true
      }
    }
  }
}
```
