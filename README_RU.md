**LinkenVisuals** — клиентский мод нового поколения для Minecraft Fabric 1.21.11, ориентированный на визуальное улучшение игры, кастомизацию и производительность. Мод построен на базе современного графического пайплайна Blaze3D от Mojang и специализированных GLSL шейдеров, предлагая пост-обработку картинки, эффекты рук от первого лица, косметику и питомцев, интерактивный HUD и полноценный медиаплеер с синхронизированным отображением текста песен (LRC).

## ✨ Основные возможности

### 🎨 Продвинутые пайплайны пост-обработки
- **Ambience & Bloom**: многоуровневая пирамида блума (даунсемплинг в 1/2, 1/4 и 1/8 разрешения), тонкая настройка экспозиции, контраста, насыщенности и кинематографичной виньетки.
- **Процедурное небо (Shader Sky)**: собственный рендерер инвертированного куба неба из 36 вершин с расчетом астрономического времени, плотности звезд и градиентных акцентов.
- **Экранный дождь (Rain)**: физически корректное преломление капель и искажение картинки в зависимости от силы осадков.
- **Эффекты ударов и убийств**: волновые пузыри искажения в экранном пространстве (Hit Bubbles) и вспышки при уничтожении противников (Kill Effects).

### ✋ Кастомизация рук от первого лица и визуальные эффекты
- **Обводка рук (Hand Outline)**: извлечение геометрии рук через дельту буфера глубины (`Line`, `Glow`, `Aura`, `Energy`).
- **Следы движения и дым (Hand Trails)**: темпоральный эффект шлейфа и дыма за оружием и руками в движении.
- **Редактор положения рук (Hand Editor)**: детальная настройка смещения, вращения и масштаба предметов в основной и второй руке.
- **View Model**: донорские числовые смещения X/Y/Z и раздельный масштаб по осям для основной и второй руки, независимо поверх редактора рук.

### 🦜 Косметика, питомцы и вэйпоинты
- **11 скинов питомцев**: Летучая мышь, Попугай, Ворон, Фея, Пчела, Векс, Лиса, Свинка, Жаба, Рыба-шар и Слизень — клиентские мобы, которые летают, ходят или парят рядом с вами; настраиваются радиус, высота, скорость, размер, прозрачность и свечение (включая цвет).
- **ULT ворона — бинд «Pet ULT»**: 19-секундная сцена иллюзий — ворон взмывает, 42 иллюзорных ворона спиралью слетаются сквозь туман из перьев, формация держится, ломается и рассеивается под оригинальный звуковой эффект, после чего питомец возвращается на плечо.
- **Персонаж Rudy**: опциональная полная замена модели игрока (модель со Sketchfab от amogusstrikesback2, CC BY 4.0) через настройку **Character** в косметике.
- **Вэйпоинты**: клиентская команда `/way` (`add <имя> me`, `add <имя> <x> <y> <z>`, `remove`, `list`, `clear`) с маркерами в мире и сохранением в `config/linkenvisuals_waypoints.json`.
- **Target ESP**: маркер вокруг сущности под прицелом — режимы Original, Ghosts, Circles и Crystals; плавно появляется и затухает, не рисуется сквозь стены и пропускает невидимых игроков без видимой экипировки.

### 🎵 Встроенный медиаплеер и текст песен в реальном времени
- **Интеграция с Windows Media**: прямое взаимодействие с WinRT (System Media Transport Controls) — автоматическое определение трека из Spotify, Apple Music, YouTube Music, Deezer, Яндекс Музыки, Foobar2000 и браузеров.
- **Синхронизированные слова (LRC)**: моментальная подгрузка таймингов текста песен через API lrclib с отображением текущей и следующей строк в HUD.
- **Обложки альбомов**: асинхронное получение оригинальной обложки из iTunes API с процедурной градиентной генерацией при отсутствии сети.

### 🖥️ 100% Кастомный интерфейс, Редактор меню и пресеты
- **Интерактивный редактор главного меню**: Полноценный визуальный редактор прямо в игре (кнопка в Настройки -> вкладка Стиль). Перетаскивание кнопок мышью, изменение масштаба колесиком или за угол, установка своих фотографий на фон и наложение шейдеров.
- **Стилевые семейства на этапе сборки**: обычный jar — только **Linken** (главное меню, Link GUI и HUD-стили Linken). Сборка `gradlew build -Pstrange` даёт **StrangeVisuals-only** jar (`linkenvisuals-strange-<version>.jar`): меню Vanilla/Beta, ClickGUI Classic/Beta и legacy Strange HUD. Стиль другого семейства нельзя включить в рантайме.
- **Свои фото и шейдерные эффекты на фоне**: Положите любое фото в `.minecraft/linkenvisuals/background.png` или выберите путь, настройте затемнение и шейдерный оверлей (Bloom Pulse, Starfield, волны или зернистость).
- **Кастомное главное меню**: Полностью переработанное меню со скином игрока, физикой сглаживания (spring ease), часами и кнопкой Mod Menu.
- **Кастомный браузер серверов**: Асинхронный список с живым пингом, индикаторами задержки, поддержкой форматирования MOTD, плавным скроллом и встроенными диалогами добавления, редактирования и прямого подключения.
- **Единый центр настроек**: Вкладки **Стиль** (пресеты и запуск редактора), **Графика** (дистанция прорисовки, FPS, FOV, VSync), **Звук** (общая громкость и каналы), **Модули** (быстрые тумблеры и вызов ClickGUI) и **Система** (ресурс-паки, бинды, доступ к ванильным настройкам, переключатель языка).
- **Кастомные экраны загрузки**: Замена ванильного фона на динамический GLSL `BackgroundPipeline`, пульсирующий логотип и адаптированные под текущий стиль индикаторы подключения к серверу и загрузки мира (Beta/Vanilla; splash и загрузка Linken — в фазе M2).

### 🌐 100% Локализация (Мультиязычность)
- **Автоопределение языка игры**: Мод на лету определяет язык Minecraft и активирует соответствующий перевод.
- **Поддерживаемые языки**: Полный перевод интерфейса и настроек на **Русский** (`ru_ru`), **Украинский** (`uk_ua`) и **Английский** (`en_us`).
- **Поддержка шрифта MSDF**: Векторный рендерер шрифта с поддержкой всех букв кириллицы и украинского алфавита.

### 🎛️ Современный Fluent ClickGUI и система настроек
- **Удобные категории**: `Combat`, `Movement`, `Visual`, `Player`, `Misc`, `Config`.
- **Spring-анимации**: плавные физические переходы и анимации интерфейсов и контейнеров.
- **Палитра цветов и слайдеры**: точная настройка цветов (RGB / HSV) и числовых значений.
- **Сохранение конфигурации в JSON**: все переключатели, бинды, слайдеры, язык, стиль и раскладка меню автоматически сохраняются в файл `.minecraft/config/`.
- **Интеграция с Mod Menu**: отдельная кнопка перехода в список модов добавлена прямо в главное меню и настройки.

## 🛠️ Сборка

```powershell
cd source
.\gradlew.bat build                 # только Linken: build/libs/linkenvisuals-<version>.jar
.\gradlew.bat build -Pstrange       # только Strange: build/libs/linkenvisuals-strange-<version>.jar
```

Семейство вшивается при компиляции и не переключается из настроек, конфигов или горячих клавиш. Обычная сборка даёт только **Linken**; `-Pstrange` — только **StrangeVisuals** (Vanilla/Beta меню, Classic/Beta ClickGUI, legacy Strange HUD) без возможности включить Linken-стиль.

## ⌨️ Управление и горячие клавиши

| Действие | Клавиша по умолчанию | Настраивается |
| :--- | :---: | :---: |
| **Открыть / Закрыть ClickGUI** | `Правый Shift` | Да (в настройках управления Minecraft) |
| **Привязать клавишу к модулю** | Нажать на модуль в GUI и нажать клавишу | Да |
| **Сбросить привязку модуля** | Нажать ПКМ по кнопке бинда | Да |
| **Запустить ULT ворона** | Не назначена — бинд **Pet ULT** в ClickGUI → Cosmetics | Да |

**Клиентские команды:** `/way` (алиас `/waypoint`) — `add` · `remove` · `list` · `clear` (вэйпоинты обрабатываются на клиенте и не отправляются на сервер). `/lvtest` (алиас `/lvautotest`) — `start` · `stop` · `status`: внутриигровой смоук-тест — открывает оба GUI и инвентарь, спавнит мобов без ИИ (при наличии читов), бьёт их, переключает все модули, прогоняет все настройки рендера, восстанавливает конфиг и пишет отчёт в `logs/linkenvisuals-autotest-<timestamp>.log`.

## 🛠️ Сборка из исходного кода

### Требования
- [Java Development Kit (JDK) 21](https://adoptium.net/) или новее.
- Установленный Git.

### Инструкция по сборке

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/KurumaOfficial/LinkenVisuals.git
   cd LinkenVisuals/source
   ```

2. **Соберите JAR-файл мода:**
   ```bash
   # В Windows (PowerShell):
   .\gradlew build

   # В Linux / macOS:
   ./gradlew build
   ```

3. **Готовый файл:**
   Скомпилированный файл мода будет находиться по пути:
   ```text
   source/build/libs/linkenvisuals-<version>.jar
   ```

4. **Запуск тестового клиента:**
   ```bash
   .\gradlew runClient
   ```

5. **Внутриигровой автотест (опционально):**
   ```bash
   .\gradlew runAutotest
   ```
   Зайдите в любой мир (или передайте `-PautotestWorld=<имя-сохранения>` для quick-play) — драйвер стартует сам через 2 секунды. Флаг `-PautotestQuit=true` закроет клиент после отчёта. Для мобов и `/tp` нужны читы; без них всё равно выполняются GUI- и модульный прогон.

## ⚙️ Файл конфигурации

Настройки хранятся в виде JSON-файлов в папке игры (`.minecraft/config/`):

- `linkenvisuals_config.json` — состояния модулей, бинды, настройки
- `linkenvisuals_hud.json` — раскладка элементов HUD
- `linkenvisuals_potion_layout.txt` — раскладка трекера зелий
- `linkenvisuals_hands.json` — поза рук
- `linkenvisuals_macros.json` — макросы
- `linkenvisuals_menu.json` — стиль главного меню
- `linkenvisuals_accounts.json` — менеджер аккаунтов
- `linkenvisuals_waypoints.json` — вэйпоинты, добавленные через `/way`
- `linkenvisuals/configs/<name>.json` — именованные профили конфигов

Пример содержимого:
```json
{
  "modules": {
    "Ambience": {
      "enabled": true,
      "keyCode": -1,
      "settings": {
        "Exposure": 1.15,
        "Contrast": 1.05,
        "Saturation": 1.20,
        "Vignette": 0.35,
        "Fog": true
      }
    }
  }
}
```
